CN4 配線 / HWTO

安全リレーが HWTO 入力をどう駆動するかを切り替えられます。 HWTO1 = CN4 11/12、HWTO2 = CN4 26/27。jumper は付属ジャンパーでの短絡 (常時 ON)、open は未接続 (常時 OFF) です。

3D モニタ

node ごとのモーターを表示し、実位置 (6064h) に合わせて軸を回します。 形状は STEP の実寸 (scripts/step_bbox.py で実測) に基づく近似です。 ドラッグで回転、ホイールでズーム。

CAN フレームログ

受信フレームに加え、omsim 自身が送信したフレーム (SDO レスポンス / boot-up / Heartbeat / EMCY / TPDO / SYNC / node guarding 応答) も 表示します。SocketCAN の receive_own_messages は既定で無効ですが、 送信経路 (network.bus.send) をラップして記録しているためです。
